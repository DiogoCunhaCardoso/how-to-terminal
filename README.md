# How to Terminal

A beginner-friendly guide to learning the Linux command line. This documentation is designed to take you from total beginner to someone who feels comfortable in a terminal environment.

## About

This project teaches terminal fundamentals using **Bash** - the most common shell on Linux systems. The guide is structured in chapters that build on each other:

1. **Terminology** - Kernel, Shell, Terminal, Distribution
2. **Navigation** - `ls`, `cd`, `pwd`, filesystem tree
3. **Filesystem** - Creating, copying, moving, deleting, viewing, and editing files
4. **Permissions** - Who owns what and how to change it
